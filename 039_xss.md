# Cross-Site Scripting (XSS)

XSS is a security vulnerability where an attacker injects malicious JavaScript into a web page. The script runs in another user's browser and may steal cookies, session data, or modify page content.

In Rails, protect against XSS by relying on automatic HTML escaping in views, validating and sanitizing user input, and avoiding `html_safe` or `raw` for untrusted content. Content Security Policy (CSP) provides an additional layer of protection.
